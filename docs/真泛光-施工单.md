## 二、目标：三趟链

```
① rt_comp.comp     主射线 + 阴影 + 反射 + 材质  →  写 imgScene（原 g_rtx.img 改名或保留 ✓）
② bloom_pre.comp   亮部提取（阈值 + 软膝）      →  写 imgBright（1/2 分辨率 ✓ 省一半带宽）
③ bloom_blur.comp  可分离高斯（横一趟 + 纵一趟，共用同一 shader 用 push constant 区分方向 ✓）
                                               →  写 imgBloom（1/2 分辨率）
④ 合成            在 ① 的着色器里读 imgBloom 加上去 ✗ 会造成同帧读写冲突 ✗
                  ⇒ 改为在 ③ 里直接把 bloom 叠加进 imgScene 的副本 ✗ 冲突
                  ⇒ **正解**：合成放在 ② 的第一趟（读 imgScene 的采样 + 写 imgBright）✗ 语义不合
                  ⇒ **推荐**：新增 ④ composite.comp（读 imgScene + imgBloom → 写 imgFinal），回读 imgFinal ✓
                     —— 代价：多一次全分辨率 dispatch ✗ 但语义最干净 ✓ 也便于以后加色调映射/AA ✓
```

**推荐最终链**：`rt_comp → bloom_pre(1/2) → bloom_blur(1/2, 双向) → composite(全分辨率) → 回读` ✓

## 四、验收标准（每项都可测 ✓）

| 项 | 判据 |
|---|---|
| 亮部真外溢 | 把**镜面高光**调到过曝 ⇒ 光晕出现在**高光周围**（不再只在灯附近 ✓） |
| 阈值可调 | 阈值 0 ⇒ 全屏发亮；阈值高 ⇒ 只有最亮点晕开 ✓ |
| 强度/半径可调 | 画面随即变化 ✓ 且**帧时间**随半径上升 ✓ |
| 性能 | 1024² 全链应在 **+1~3 ms** 内（1/2 分辨率两趟 + 一次合成 ✓ 参照现状 8~11 ms ✓） |
| 不回归 | 关闭泛光（强度 0）时，画面应与 12.6 **逐像素一致** ✓ |

## 五、风险与备选

| 风险 | 备选 |
|---|---|
| 描述符/管线接线出错 ⇒ 光追初始化失败 ✗ | 失败即返回错误串（现有 `return "X …"` 模式 ✓ 不会崩 ✓）；断言保护补丁 ✓ |
| 推送常量超 128 字节 ✗ | 合并可压缩字段（`fov`/`shadowOn` 可打包进 `rtOpt` ✓）；或用 **第二个推送常量范围** ✗（不便）⇒ 首选合并 ✓ |
| 1/2 分辨率泛光有明显块状 ✗ | 双线性采样 + 两趟可分离模糊即可接受 ✓（业界常规做法 ✓） |
| 时间不够一次做完 ✗ | **分两步**：先做「亮部提取 + 单趟模糊 + 合成」（不分离方向 ✓）⇒ 仍比解析光晕真实得多 ✓ 再补第二趟 ✓ |
